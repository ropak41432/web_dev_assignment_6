# Module 6 Assignment: Personal Profile Webpage Using HTML

A semantic, responsive, and clean personal profile webpage built in HTML5 for **Module 6 Assignment** of the Ostad Full-Stack Web Development Course.

---

## Assignment Requirements Checklist

| # | Task / Requirement | Implementation Details in `index.html` | Status |
| :---: | :--- | :--- | :---: |
| **1** | **Structural Tags** | `<html>`, `<head>`, `<title>`, `<body>`, `<h1>`, `<h2>`, `<p>` | Complete |
| **2** | **Text Formatting** | `<b>` (bold), `<i>` (italic), `<u>` (underline), `<mark>` (highlight) | Complete |
| **3** | **Interactive Form** | Name, Email, Password, Gender (`radio`), Hobbies (`checkbox`), and Submit button | Complete |
| **4** | **Academic Table** | 4 rows × 4 columns detailing degrees, institutions, passing years, and results | Complete |
| **5** | **Multimedia** | Profile photo (`<img>`), audio player (`<audio>`), and video player (`<video>`) | Complete |
| **6** | **Semantic Elements** | `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>` | Complete |
| **7** | **Interactive Elements** | `<details>` and `<summary>` tags, plus a clickable `<button>` | Complete |
